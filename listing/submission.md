### Maintainer notes

Live casting asks before changing the system: with ufw on it adds one rule for TCP 8554 from the LAN subnet, and for window casts it sets xdg-desktop-portal-hyprland's custom_picker_binary to the plugin's picker, which runs the previous picker for every other screen share. `screenrig-omarchy teardown` undoes everything the plugin set up. The first live cast downloads mediamtx v1.21.3 and verifies it against the release's published SHA-256. The plugin needs the screenRIG CLI's sign-in.
